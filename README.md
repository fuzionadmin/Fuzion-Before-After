# Fuzion Hair Care — Before & After

A mobile-friendly Before & After photo comparison page designed for GitHub Pages.

## Features
- Upload Before and After photos independently
- Mobile camera/file picker support
- Edit button for each photo
- Crop, zoom, drag/reposition and rotate
- Reset edits
- High-resolution JPG comparison download
- Client Name and Client ID fields
- Company logo at the top
- Company information at the bottom
- No server/database required: photos stay in the user's browser

## GitHub Pages setup
1. Upload all files to a GitHub repository.
2. Put your company logo in the same folder and name it `logo.png`.
3. Edit the company information in `index.html`.
4. Commit/push the files.
5. In GitHub: Settings → Pages → Deploy from a branch → select `main` and `/root`.
6. Open the generated GitHub Pages URL.

## Important
This version is client-side only. Uploaded photos are not sent to a server or stored in a database. They exist in the browser while the page is being used.
